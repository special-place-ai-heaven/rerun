# @rerun/i18n

The language packs of Rerun: the supported locales, the message catalogs, the formatters for dates
and numbers, and the scripts that keep the packs in step with the English source.

```
src/locales.ts      SUPPORTED_LOCALES, resolveLocale(), the cookie name
src/format.ts       dates, relative times, numbers, sizes, durations, all taking a locale
src/messages.ts     loadMessages(locale): English, the pack over it, then Rerun Cloud's strings
src/pseudo.ts       the en-XA pseudo-locale (development only)
messages/en/*.json  the source, one file per namespace, written by hand
messages/fr, es, pt, de  generated by `pnpm i18n:translate`, committed, reviewed in the diff
glossary.json       words kept as they are, imposed translations, tone per language
```

## Writing a string

Every string a person sees goes through `t()` (`useTranslations` in a client component,
`getTranslations` on the server). The source is English, in `messages/en/<namespace>.json`.

- A key says what the string is, not what it reads: `chat.composer.placeholder`.
- One sentence is one key. Never glue translated pieces together: variables and plurals go inside
  the message, in ICU (`{count, plural, one {# file} other {# files}}`).
- A string whose meaning is not obvious from its key gets a note under `_context` at the root of its
  namespace, keyed by its dotted path. The translator reads it; the app never ships it.

Then:

```bash
pnpm i18n:translate   # translates what is new or changed into every pack (Claude, ~cents)
pnpm i18n:check       # what the CI runs: no key missing, no stale translation, placeholders intact
```

`i18n:translate` needs an Anthropic key (`ANTHROPIC_API_KEY`) and prints its estimate before it
spends anything (cap: `--max-usd`, 20 by default). A translation fixed by hand in a pack is recorded
with `pnpm i18n:translate --accept`.

## Adding a language

1. Add it to `SUPPORTED_LOCALES` in `src/locales.ts` as `beta`, and its pack to `PACKS` in
   `src/messages.ts`.
2. `pnpm i18n:translate --locale de`, then `pnpm i18n:check`.
3. The Supabase auth emails (`supabase/templates/*.html`) get their branch for it.
4. Its WhatsApp templates are submitted to Meta.
5. Its App Store listing is added (`apps/mobile/store.config.json`).
6. The landing adds it to its routing; the sitemap follows.
7. `pnpm verify:ui --locale de`, every capture looked at, then the status moves to `stable`: only
   `stable` languages are offered in the pickers.

Right-to-left languages are out of scope until the `ml-`/`mr-` classes move to `ms-`/`me-`.
